## 决策

在 `memory/` 下 `git init`，git 是知识库唯一的版本权威。Obsidian Git 插件与仓库共用；Pickpen 改为只读（不再写盘）。

## 理由

- 自动化写入必须可撤销：git 提供 `diff` / `checkout` / `bisect`，是"永不删除"承诺的实际兑现方式。
- Pickpen 与 git 同时写会产生 conflict copy，两套历史无法对账（schema §9 已列为待决）。
- 单一权威才能支撑"单写通道"：DSH 写、其它 agent 只读，版本层也只有一条线。

## 放弃的替代方案

- **双写（git + Pickpen）**：冲突副本与两套真相，排查成本高于收益。
- **在 `Obsidian Vault/` 根建仓**：会把项目与素材一起纳入，提交噪声大、权限面扩散。
- **不建仓**：自动追加原文没有 undo，一次误写就永久污染原文层。

## 复审条件

- Pickpen 若提供"只读/导出"模式且确认不写库，可重新评估是否恢复。
- 引入云同步或多人协作时，"删除"语义需要重新定义。
