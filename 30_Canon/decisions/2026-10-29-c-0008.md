## 决策

知识库采用一套**「文件为真相、索引为派生物」的分层长期记忆架构**，由五块组成，缺一不可：

1. **三层目录**：`10_Raw/` 原文（只增）、`20_Digest/` 摘要（原子 / 主题页 / 工作页）、`30_Canon/` 结论（决策 / `core.md`）。目录只表达抽象层级，生命周期全部写在 frontmatter。
2. **五步管线**：轮末自动落盘 → 静默窗口门控抽取 → 语义裁判（deepseek-flash）→ 校验落盘 → 每日整理。前两步由 `@local/kb-panel` 触发器驱动，规则在 `_meta/scripts/kb.mjs`。
3. **双闸门注入**：`core.md` + 最多 5 条 `active` 且 `scope ∈ {global, 本会话项目}` 的记忆；`type ∈ {topic, work, session}` 与 `inbox` / `system` / `unclassified` 永不进入这 5 条——由代码强制，不依赖模型自觉。
4. **工作层（v1.4）**：`20_Digest/work/` 下的 `type: work` 状态页，一个 scope 一页，记录阶段 / 在办 / 未决 / 下一步。它是**状态不是记忆**：不占 5 条预算，只在新会话贡献一条 ≤420 字的「项目简报」。
5. **单写通道**：只有 DSH 经插件与 `kb.mjs` 写库；`git` 是唯一权威，索引可由笔记重建，删除靠历史找回。

```
Obsidian Vault/memory
├─ 10_Raw      原文：会话、剪藏（只增不改）
├─ 20_Digest   摘要：atoms/ · topics/ · work/
├─ 30_Canon    结论：decisions/ · core.md
├─ 90_Archive  出口（默认不用，归档在索引层）
└─ _meta       schema · scripts(kb.mjs) · plugin · templates · state(gitignore)
```

## 理由

- **对抗失忆**：新会话自动带 `core.md` + 确认过的记忆 + 项目简报，不用重新交代；日常召回预算 ≤800 token。
- **对抗污染**：写入与生效分离——裁判只负责分类，写入默认 `inbox`；人确认才 `active`。判错最多少召回，不会把错的行为带进对话。
- **对抗臃肿**：只有「一年后回看还有用」的内容才进摘要层；工作指令与过程日志只留在原文层。工作层只存状态摘要，避免任务清单与施工日志挤占记忆预算。
- **对抗不可逆**：默认归档不删除；物理删除必须一次性票据 + 人工输入密钥；索引可重建，文件与历史在 git 里。
- **可迁移**：纯 Markdown + frontmatter + git，不绑定 Obsidian、DSH 或任何厂商；换宿主只换插件层。

## 关键不变量

1. 不搬家：文件出生在哪层就永远待在哪层；晋升 = 高层新建 + `up:` 回指。
2. 不删除：只降权、只归档；物理删除是唯一例外（§8.1 两道闸）。
3. 索引是派生物：`_meta/*.jsonl` 禁止手改，只能 `rebuild`。
4. 页面不是记忆：`topic` / `work` 永不进 5 条注入预算；工作页只出简报。
5. 一个 scope 一个 active 工作页；同 scope 恢复冲突会被拒绝。
6. 状态变更、晋升、新建工作页都写 `_meta/log.md`，可审计。

## 放弃的替代方案

- **单层文件夹 + 标签**：检索成本随规模上升，生命周期无处安放；否。
- **每轮全量注入历史**：token 爆炸且污染，无法审计；否。
- **全量向量检索/RAG**：当前规模（数百篇）grep + summary 足够，引入索引同步与黑盒召回不划算；留作规模变大后的扩展，不进 v1。
- **把任务/待办当原子记忆**：会占注入预算、快速过期、把施工日志带进对话；改为工作页 + `consolidate` 诊断。
- **新开 `40_Work/` 顶层目录**：破坏「目录 = 抽象层级」不变量；工作层放在摘要层之下（`20_Digest/work/`）。
- **云端 SaaS 记忆**：不可迁移、不可审计；否。

## 复审条件

- 主索引超过 3000 行或 grep 明显变慢 → 启用归档/语义检索。
- 注入经常触顶 5 条或简报逼近 420 字 → 调整预算与工作页写法。
- 出现多 agent / 多用户并发写 → 重新审视单写通道与锁。
- 更换宿主、插件体系或 Obsidian 时 → 只需替换 `_meta/plugin/`，数据层不变。
