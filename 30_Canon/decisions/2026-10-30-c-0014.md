# 记忆库边界与备份策略

## 决策

1. **项目库位置**：固定在项目内 `<project>/.dsh-memory/`。项目库随项目移动，便于导入/删除；项目仓库必须把 `.dsh-memory/` 加入 `.gitignore`（或用 `.git/info/exclude`），禁止把记忆库提交到业务仓库。
2. **接入方式**：项目库必须显式 `kb attach` 登记到用户级 `projects.json`；克隆仓库自带的 `.dsh-memory/` 不自动加载。插件只从 cwd 向上找最近一个已登记项目库。
3. **默认读写**：项目库默认**只读注入**。写入必须由用户显式 `kb attach --write` 授予，授权记在用户级 registry；`attach --write` 与 `delete` 一样要求真实 TTY，项目自身 `project.json` 不能自开写入。外部库命中会话 cwd 后由插件懒建独立 ingestor/judge，写入只落该库。
4. **原文公开边界**：`10_Raw/` **永不进入公开仓库或公开快照**。公开仓库只含脱敏摘要、决策、规则和代码；对话原文留在本地完整库与私有备份。
5. **备份策略**：公开快照是单向脱敏导出，不是备份。完整库（含 `10_Raw/` 与 git 历史）使用**私有 GitHub 仓库的完整 git bundle** 作为异地备份；bundle 含所有 refs，排除 `_meta/state/` 与 `access.jsonl`。每次重大里程碑后更新备份，不在公开仓库保存备份产物。2026-10-30 已建立私有备份：`shehuilaoliumang/dsh-memory-private`；2026-10-31 审计清偿版发布后更新为 release `backup-2026-10-31-13284a8`，bundle 630,440 字节（commit `13284a8`）。
6. **归档备注**：`2026-10-29-a-0002` 已补归档说明，注明其为施工日志、违反 a-0016，保留原文但不注入、不公开。

## 理由

- 项目内 `.dsh-memory/` 符合“每个项目带一个本地记忆库”的产品定义；风险是误提交，因此用 `.gitignore` 纪律 + 显式 attach 双保险，而不是把库搬到用户目录，避免项目迁移/分享时记忆丢失。
- 默认只读是最小权限：在任意仓库自动写入会把业务代码/对话写进不受控路径；先验证只读注入，再按项目开启写入。
- 原文包含完整对话、路径、可能的密钥与个人上下文；公开不可逆，历史提交也不会因删除而消失。宁可不公开，也不靠人工逐条脱敏。
- 公开快照不能替代备份：它排除了 raw/state，且是单向导出。私有 bundle 至少能恢复完整历史与原文；备份放在私有仓库而不混进公开仓库。
- a-0002 的教训是“裁判也会把施工日志写进记忆”；保留并标注比删除更符合审计原则。

## 放弃的替代方案

- **项目库放用户目录 `~/.dsh-memory/projects/<hash>/`**：不随项目移动，项目迁移/清理后记忆成孤儿；对“项目自带记忆”目标不利。
- **自动加载任意 `.dsh-memory/`**：克隆仓库即可注入任意文本，等于 prompt injection 通道；不采用。
- **默认允许外部项目写入**：raw/裁判/脱敏/索引都要按库隔离，未验证前风险高；不采用。
- **公开 `10_Raw/`**：不可逆且含敏感上下文；不采用。
- **把公开快照当备份**：缺 raw/state，且不能恢复完整 git 历史；不采用。
- **只备份笔记目录、不备份 git 历史**：丢失变更审计和已删/已改内容，无法回滚；不采用。

## 不变量

1. `.dsh-memory/` 不进入业务仓库提交；项目库必须显式 attach。
2. 项目库默认只读；写入必须显式开启并先有隔离测试。
3. `10_Raw/` 不进入公开仓库、公开快照或公开 CI 产物。
4. 公开快照可以重建；完整库备份必须能恢复原文与 git 历史。
5. 归档条目不删除；归档原因写入正文备注并保留。
6. 备份产物只进私有存储，不进公开仓库。

## 复审条件

- 项目库误提交到业务仓库：改为用户目录或增加 pre-commit 检查。
- 需要跨机器同步项目记忆：评估私有 remote/加密 bundle，不把公开快照当同步通道。
- 外部项目写入开启后出现串库/污染：回退为只读并加库级锁。
- 私有备份恢复演练失败：改为双备份（本地 + 另一云/离线介质）。

## 验收

```powershell
# 项目库默认只读、显式接入
node _meta/scripts/kb.mjs init --root <project>\.dsh-memory --slug demo
node _meta/scripts/kb.mjs --root <project>\.dsh-memory attach
node _meta/scripts/kb.mjs --root <project>\.dsh-memory validate

# 完整库私有备份（示例）
git bundle create <backup-dir>\dsh-memory-<date>.bundle --all
# 上传到私有 GitHub 仓库 release asset；不进入公开仓库
```
